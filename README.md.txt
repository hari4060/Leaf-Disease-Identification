Project Overview:

The Leaf Disease Identifier is a deep-learning-based application designed to identify plant leaf diseases from images. It uses image processing and a Convolutional Neural Network (CNN) to classify leaf images into different disease categories.

Technologies Used
- Python
- TensorFlow and Keras
- OpenCV
- NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Flask

Features
- Leaf image processing
- Deep learning-based disease classification
- Prediction of disease categories
- Model training and evaluation
- Confusion matrix and classification report
- Flask-based application interface

Project Structure

Installation and Setup
1. Clone this repository.
2. Install the required packages

Run the model training script:
python main.py

Run the Flask application:
python app.py

Model
The project uses a Convolutional Neural Network (CNN) for leaf disease classification.
